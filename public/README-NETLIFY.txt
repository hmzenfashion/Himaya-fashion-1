=============================================================
             HIMAYA FASHION - NETLIFY DEPLOY GUIDE
=============================================================

পদ্ধতি ১ (Netlify Drop - সবচেয়ে সহজ ড্র্যাগ অ্যান্ড ড্রপ):
-------------------------------------------------------------
1. https://app.netlify.com/drop সাইটে যান।
2. এই জিপ ফাইলটি আনজিপ (Extract) করার পর ভেতরে "dist" নামের 
   যে ফোল্ডারটি পাবেন, শুধুমাত্র সেই "dist" ফোল্ডারটি টেনে 
   Netlify-র ড্রপ বক্সে ছেড়ে দিন।
   (মনে রাখবেন: পুরো রুট ফোল্ডার নয়, শুধু "dist" ফোল্ডারটি আপলোড করবেন)।
3. সাথে সাথে আপনার ওয়েবসাইটটি Netlify-তে লাইভ হয়ে যাবে!

পদ্ধতি ২ (GitHub / GitLab এর মাধ্যমে Netlify তে কানেক্ট করলে):
-------------------------------------------------------------
প্রজেক্টে "netlify.toml" ফাইল যুক্ত করা আছে।
GitHub এর সাথে কানেক্ট করলে Netlify স্বয়ংক্রিয়ভাবে:
- Build Command: npm run build
- Publish directory: dist
- SPA Redirect: /* -> /index.html (200)
নিজে থেকেই কনফিগার করে লাইভ করে দেবে!

Firebase ডোমেন অনুমতি (Google Login / Auth এর জন্য):
-------------------------------------------------------------
Firebase Console (Authentication -> Settings -> Authorized domains)-এ 
গিয়ে আপনার netlify ডোমেনটি (যেমন: himayafashion.netlify.app) যোগ করে দিন।
